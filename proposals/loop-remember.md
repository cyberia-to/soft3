# the loop remembers — remember · prove · link · focus

> an iteration on the loop at [soft3.org/loop](https://soft3.org/loop) (link → prove → focus). the current ring reads well but says nothing other stacks cannot say: any system links, proves and ranks. what only this stack does is **answer without computing** when the computation was ever done — by anyone, anywhere — because a proof in the book ([[bbg]] + [[zheng]]) is as good as the computation itself. the whitepaper calls it global memoization (§7.5: key `(H(subject), H(formula))`, value `H(result)`); the channel page calls the book "the planetary computation cache". the loop never names it. this draft puts it at the front.

## what is wrong with the current loop

| current | reads as | what it hides |
|---|---|---|
| LINK — a thought becomes a link, with weight | writing | that the book is read before it is written |
| PROVE — every computation leaves a proof | the machine | that the proof is kept so nobody computes it again |
| FOCUS — the whole graph settles into one focus | the network | fine |
| "the focus is the next thought" | the return path | weak: a mood, not a mechanism |

the return path is the problem. in this stack the return path is literal: the next thought asks the book first, and most of the time the book already knows.

## the loop, iterated

four verbs, one gate at the front:

| verb | who | one line | parts |
|---|---|---|---|
| REMEMBER | the book | what anyone ever proved, the book answers — verified in ~100 ns, never recomputed | cybergraph · bbg · zheng (verify) |
| PROVE | the machine | what nobody proved, the machine computes once and leaves a proof | trident · nox · joy |
| LINK | a mind | the proof becomes a link, with weight — the book grows by exactly one fact | neural · cy |
| FOCUS | the network | the whole graph settles into one focus; the focus is the next question | tru · foculus · soft3 |

arcs:

- remember → prove: *the book is silent* (a cache miss is the only reason to compute)
- prove → link: *every computation leaves a proof*
- link → focus: *every link has weight*
- focus → remember: *the next thought asks the book first*

motto candidates for the centre: **computed once, remembered by all** · *ask the book before the machine* · *nothing is computed twice*.

## why remember is the headline verb

- a cache elsewhere is trusted by authority (the CDN, the database owner). here it is trusted by proof: your result + your proof = my result, with no trust in you. that is the sentence no other stack can write.
- it is the economics: the one who proved first is paid each time the world remembers instead of recomputing ([[tru/specs/rewards|rewards]], the viewing economy). focus is how the payment is weighed; remember is why there is anything to pay for.
- it is the ~100 ns on the front page made into a verb. verify-not-recompute is remember.

## what to decide

1. four verbs or three. three keeps the ring symmetric (remember · prove · focus, with link as the fabric the ring runs on); four names the write explicitly and keeps the root verb *link* on the page. this draft prefers four.
2. the order of entry. starting the ring at REMEMBER makes the gate explicit — nothing is computed before the book is asked.
3. colours: four verbs over seven facets. remember = mass (what is it made of: facts), prove = form (the rules), link = life (what lives: the book grows), focus = play (coordination).
