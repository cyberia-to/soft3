the invariant the ladder needs and the code does not yet enforce: a warrior proves against the root it is given, so the node must bind that root to the finalized tip (registry row 40). bbg is state; cybergraph is the change of state; the warrior reads the first and never performs the second.

outside phase 1 — components the ladder does not carry yet

fs mount · ward authorize · neural mean · sigma evaluate · eidos certify · wysm sandbox · kern shade · lytics measure — specified, dormant or cut from phase 1 by the launch contract; they join a rung when their owner says so. grown on soft3, not of it: erga mine, studio sign. the one list every surface is checked against is release/components.toml.

the rule. a layer is something that ships and is used on its own, and it knows only the layers below it. every component of the phase-1 manifest appears exactly once, in the layer that first needs it; a substrate enters once and every layer above pins it. the release train cuts candidates from 0 upward, so a red substrate reddens everything and a red body never touches the node.

why the substrate is zero and the language is one. the field, the hash and the machine exist without any program written; trident exists only because they do. the language depends on nebu, hemera and nox and nothing above them: it never executes and never proves. commitments enter one layer up, with the warrior: nox's pattern 17, look, reads state against a commitment through an abstract LookProvider; the machine defines that slot and ships with a null provider, lens is the Brakedown provider that fills it, and the first code that requires it is zheng. one open decision could move lens down: if a particle is defined as hemera over the lens commitment to the data, as the particle page says, rather than hemera of the data, as every crate computes today, then identity itself needs lens and it becomes substrate. that is why it could ship three times before the rest of the ladder existed.

every node has a genesis. a node is a neuron running its own book: state from the first block, signed by that neuron, kept in its vault. there is no node without a genesis, because there is no neuron without a book. a network is the case where one book is the root: it carries a token, other books register into it by name and state root, and many nodes agree on that root. bostrom and pussy are two such root books of the same node binary.

why the body is above the node. the node holds consensus state and custody; a body talks to a node: it signs through the node's custody, reads, renders, publishes. cyb is the full body, true-cyber the headless one, optica the one that renders the graph as a website. neither can order a block.

one violation this ladder exposes. true-cyber today imports a module of cyb-core, a private crate of another body, for the robot registry; the subject that both bodies share is neuron, on the node layer. the fix is a bump: true-cyber depends on neuron and the soft3 crate, and cyb-core stops being anyone's dependency but cyb's.
