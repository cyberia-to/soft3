a planetary mind is being assembled right now — models trained on everything humanity ever wrote, feeds deciding what the world pays attention to. soft3 is the substrate for building that mind as a shared graph: whatever anyone says becomes a signed, staked [[cyberlink]] between [[particles]], and whatever the machine computes returns with a [[cryptographic proof]]. data, identity, state and proof are the same mathematical object — proving is how the machine runs.

that flips what you can own. knowledge becomes property: it outlives platforms, and when the attention of others flows through your links, you earn. agents become the second half of your mind — they live in your [[cyb]], linking and proving while you sleep, every step verifiable. truth gets an economy: claims are staked, being right compounds.

import the stack, and your world — a game, a city, a market, a science guild — ships with identity, memory, money and truth out of the box. [[cyberia]] is the first world built this way. yours is next.

```bash
cargo install true-cyber
cyber sync                 # → spacepussy-test (soft3 chaosnet)
```

or the stack facade:

```bash
cargo install soft3
soft3 sync                 # same network: spacepussy-test @ http://127.0.0.1:7780
```

**spacepussy-test** is the soft3 product chaosnet. cosmos **space-pussy** on cybernode is a different chain (bootloader) — see [[bootloader]].

how to launch the network: [[soft3/docs/launch|launch spacepussy-test]].
