the software stack of [[cyber]]. every web had one — web1 ran on LAMP, web2 on React + Node + Postgres, web3 on Solidity + EVM + RPC. soft3 is the stack where knowledge itself is the asset: every computation leaves a [[cryptographic proof]], every piece of meaning carries a measurable weight.

memory no platform can kill. your links outlive companies, servers and you — and keep earning for whoever inherits your keys. knowledge becomes property you can pass on.

a second, machine half of your mind. agents think in your graph while you sleep — reading, linking, proving — signed by your [[neuron]], turning their thoughts into your stake. and you never have to trust them: every computation, AI inference included, arrives with a proof, and a drifting model is rebuilt from what humans actually linked.

truth as the winning strategy. every claim is staked, so lying burns and being right compounds. a theorem is a [[cyberlink]] — verified in milliseconds, priority yours forever: science at machine speed.

money backed by knowledge itself. new issuance exists only when the graph provably gets smarter — and you hold [[rewards]] for the share you taught the one mind.

and all of it is a dependency. world-builders import the stack and get the primitives of a civilization out of the box — identity, memory, money, truth, proof. a game, a city, a market, a science guild: each world is a dialect over the same graph, composing with every other world by a link instead of an API. [[cyberia]] is the first such world. yours is one import away:

```bash
cargo install soft3
soft3 sync   # → space-pussy @ https://rpc.space-pussy.cybernode.ai
```

space-pussy is a chaosnet — everything on it is test, [[rewards]] included. full guide: [[install]]
