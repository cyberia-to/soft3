# crystallization — the boundary and the core of soft3

the question "what is the stack, exactly" has an answer now, and it came from a drawing: [soft3.org/scheme](https://soft3.org/scheme). the stack is a **closed cybernetic loop** — say · sign · link · prove · focus · act · measure · say again — standing on one field. that shape gives a decision procedure where there used to be taste.

## the boundary rule

**a component is part of the stack iff some closure of the loop cannot happen without it.** everything else is one of two things: *enrichment* — a richer way to perform a station the loop already performs (trident is a richer way to say; honeycrisp a faster floor; wysm a wider work) — or a *product*, which consumes the loop entire (cyb, optica, erga). the rule is mechanical: to decide a component, ask which closure breaks without it. if none breaks, it is not stack.

## the four closures

the loop does not close once. it closes **four times**, each closure needing a strictly larger core and granting the graph one property:

| closure | property | minimal core | state |
|---|---|---|---|
| 1 · germ | the graph is **shared** | cell · cybergraph · mudra · radio | **closed 2026-09-01** — two cells over the wire, no server |
| 2 · proof | the graph is **trustless** | + nox · zheng · bbg on the form floor (strata · hemera · lens) | blocked — zheng opening derivation |
| 3 · mind | the graph is **one** | + tru · foculus | unwired — never deployed |
| 4 · flesh | the graph is **alive** | + mir · prysm · lytics · sigma | partial — lytics lives in production |

**shared → trustless → one → alive.** the closures compose but are not strictly serial — a trusting community can run germ+mind without proof (foculus's fork-choice is pluggable), and lytics measures today without waiting for finality. the canonical ascent is the order in which properties strengthen each other, not a dependency chain.

the trinity maps onto the closures: [[cyb]] needs flesh to be a body, [[cyber]] needs mind to be a mind, [[cyberia]] needs trustless *and* one to be a state.

## the sufficiency test

each closure is **executable**: the germ test already exists and passed — `cy wire up`, two cells, a link cast in one arriving in the other, no third party ([[wire]]). the discipline going forward: every closure gets its loop test, and a closure is claimed only when a signal demonstrably completes the circuit at that degree. proof's test: a stranger verifies a read it never trusted. mind's test: two conflicting signals, one survivor, chosen by φ* past τ. flesh's test: an act in the world measurably changes what the mind next says.

## what this changes

- **focus**: the germ core is four components. hardening those four beats widening anything else.
- **honesty**: [[status]] states map one-to-one onto closure states — the registry and the scheme now tell one story.
- **scope discipline**: any proposed component must name its station and its closure. "it would be nice" is not a station.
